# ComfyUI-Style Workflow Reference

## Purpose

Borrow useful workflow ideas from ComfyUI-style systems without copying the product.

## Borrow

- Graph as the main workspace.
- Searchable node library.
- Queue-based execution.
- Output preview.
- Saveable workflows.
- Node parameter editing in a side panel.

## Do Not Assume

Entropia Riko is not only for image generation.

It should support:

- Tensor operations.
- Model inference.
- Neural modules.
- Data transformation.
- Future training workflows.

## Basic Flow

1. Add node.
2. Configure node in side inspector.
3. Connect ports.
4. Validate graph.
5. Run graph.
6. Inspect outputs.
7. Save workflow.
