# Design

## Product Feel

Entropia Riko should feel like a focused technical tool.

It should be:

- Clean.
- Direct.
- Inspectable.
- Fast to understand.
- Dense enough for technical work.

## Main Interaction

The user builds a graph, edits selected node settings in the side panel, runs the graph, and inspects outputs.

## Design References

- ComfyUI for graph workflow patterns.
- Material Design for UI clarity.
- Procedural node tools for graph logic.

Do not use Houdini branding or imply Houdini integration.
