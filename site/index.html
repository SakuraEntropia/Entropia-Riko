Entropia Riko
节点图深度学习编辑器 · Node-graph DL editor

像搭积木一样
搭建 深度学习 工作流

Entropia Riko 是 ComfyUI 风格的节点图编辑器：在画布上连接 PyTorch 节点， 实时看训练曲线、导出干净代码、用插件扩展、用子图组织复杂模型——既能当 Python 库， 也能当桌面应用。

$ pip install entropia-riko

可选扩展：pip install "entropia-riko[tf]"（TensorFlow/Keras）· pip install "entropia-riko[hf]"（Hugging Face）

01快速开始

1
安装：上面的 pip install entropia-riko（含 PyTorch、FastAPI、numpy）。
2
当库用：导入即注册全部 194 个内置节点。
3
起服务：一条命令启动 API，浏览器打开编辑器。
# 作为 Python 库
import entropia_riko
import entropia_riko.nodes          # 注册全部 194 个内置节点
from entropia_riko.runtime.registry import default_registry

print(entropia_riko.__version__)                  # "0.1.0"
print(len(default_registry().list()))             # 194
# 启动 API 服务器（http://127.0.0.1:8000）
entropia-riko
# 等价命令
python -m uvicorn entropia_riko.server.app:app --port 8000

02它能做什么

🕸 200+ 节点

数学、张量运算、神经网络层、注意力、归一化、einsum、损失、数据加载、推理、子图引用、HF 模型。

🎨 模块化工作区

Blender 式窗口：拆分/合并/缩放任意面板，多个工作区标签与预设。

📈 实时训练曲线

SSE 流式输出每步 loss，画进 SVG 图表。

🧹 代码导出

导出 PyTorch nn.Module 或 TensorFlow tf.keras.Model，或整套项目仓库。

🧩 插件系统

一个 plugin.json + 一个 Python 入口，@register 注册节点，面板里一键开关。

🔀 子图导航

双击进入子图，Houdini 式面包屑（root / subgraph）返回，多端口输入输出。

🗂 项目即单位

像 IDE 一样以项目文件夹为单位，内置文件管理器、右键菜单、.riko 缓存。

🖥 桌面应用

内置 Electron 壳，可当独立桌面应用运行。
